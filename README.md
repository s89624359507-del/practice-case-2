Кейс-задача №2 — Счётчик
Описание проекта
Простой счётчик на HTML, CSS и ванильном JavaScript. При нажатии на «+» значение увеличивается на 1, при нажатии на «−» — уменьшается на 1. Фон окна с результатом меняется в зависимости от значения, а при достижении 10 или −10 кнопки блокируются и появляется сообщение.
 Технологии
- HTML5
- CSS3 (градиенты, flexbox, border-radius)
- JavaScript (DOM, события, classList)
 Как запустить
1. Склонируй репозиторий или скачай файлы.
2. Открой `index.html` двойным кликом в браузере.
3. Нажимай на кнопки «+» и «−».
