Отчёт по кейс-задаче №2
1. Постановка задачи
Разработать простейший счётчик с использованием HTML, CSS и ванильного JavaScript:
- интерфейс из двух кнопок («плюс» и «минус») и окна отображения результата;
- фон — линейный градиент, элементы центрированы по окну браузера, кнопки со скруглением 5px и градиентным фоном;
- при нажатии на «плюс» значение увеличивается на 1, при нажатии на «минус» — уменьшается на 1;
- фон окна результата: жёлтый при положительных значениях, зелёный при отрицательных, красный при нуле;
- при значении 10 кнопка «плюс» становится неактивной, при значении −10 — кнопка «минус»;
- при достижении 10 или −10 появляется сообщение «Вы достигли экстремального значения».
2. Ход работы
2.1. HTML-структура
Создан файл `index.html` с контейнером `.counter`, внутри которого:
- элемент `h1#result` для отображения текущего значения;
- блок `.buttons` с двумя кнопками `button#minus` и `button#plus`;
- элемент `p#message` для вывода сообщения о достижении экстремума.
2.2. CSS-стилизация
В файле `style.css` реализовано:
- линейный градиент на `body` (переход от фиолетового к синему);
- центрирование через `display: flex; justify-content: center; align-items: center;` и `min-height: 100vh`;
- кнопки со скруглением `border-radius: 5px` и градиентным фоном;
- три класса для окна результата: `.positive` (жёлтый), `.negative` (зелёный), `.zero` (красный);
- плавные переходы через `transition` для цвета фона и трансформации кнопок;
- состояние `:disabled` для неактивных кнопок (полупрозрачность, курсор `not-allowed`).
2.3. JavaScript-логика
В файле `script.js` реализовано:
- переменная `count` для хранения текущего значения;
- функция `updateUI()`, которая обновляет текст, цвет фона, состояние кнопок и сообщение;
- обработчики событий на кнопках через `addEventListener('click', ...)`;
- проверка на граничные значения: `count < 10` для «плюса» и `count > -10` для «минуса», чтобы значение не выходило за допустимые пределы;
- блокировка кнопок через свойство `disabled`;
- вывод сообщения при `count === 10` или `count === -10`.
3. Проверка работы
Проверено в браузере:
- при значении 0 окно красное, обе кнопки активны;
- при увеличении до 10 окно жёлтое, кнопка «плюс» блокируется, появляется сообщение;
- при уменьшении до −10 окно зелёное, кнопка «минус» блокируется, появляется сообщение;
- при промежуточных значениях сообщение пропадает, обе кнопки активны.
4. Вывод
В ходе работы я закрепила навыки работы с DOM, обработчиками событий, манипуляцией классами через `classList` и стилизацией через CSS-градиенты и flexbox. Программа работает корректно и полностью соответствует заданию.
